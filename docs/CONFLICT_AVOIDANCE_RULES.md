# Conflict Avoidance Rules

## File de conflict

- `pubspec.yaml`
- `pubspec.lock`
- `lib/main.dart`
- `lib/app.dart`
- `lib/core/router/app_router.dart`
- `lib/core/theme/app_theme.dart`
- `README.md`
- `docs/API_CONTRACT.md`
- database migration/schema
- seed data dung chung

## Quy tac

- Chi mot nguoi sua file core tai mot thoi diem.
- Ai can them package phai bao team va cap nhat README.
- Ai can doi model/API response phai cap nhat `docs/API_CONTRACT.md` truoc.
- Khong format toan bo repo khi PR chi sua mot module neu gay diff lon.
- Khong rename folder/module cua nguoi khac neu chua thong nhat.
- Neu can sua shared model, mo PR nho rieng truoc khi lam UI lon.
