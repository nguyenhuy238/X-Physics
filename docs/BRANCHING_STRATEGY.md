# Branching Strategy

## Branch chinh

- `main`: code on dinh, co the demo.
- `develop`: tuy chon, dung de tich hop truoc khi merge main neu team muon.

## Branch module goi y

- TV1: `feature/auth-profile`
- TV2: `feature/learning-content`
- TV3: `feature/formula-offline`
- TV4: `feature/quiz-progress`
- TV5: `feature/admin-statistics`

## Quy tac

- Moi task tao branch rieng tu `main` hoac `develop`.
- PR nho, tap trung vao mot module.
- Merge thuong qua Pull Request.
- Tag module owner khi sua folder cua nguoi khac.
