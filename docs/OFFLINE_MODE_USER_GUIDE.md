# Offline Mode User Guide

## Download A Lesson

Open a lesson while online and tap the download icon in the top bar. The app saves the lesson text, formula, and simulation for offline reading.

## Download A Chapter

Open Offline Downloads and tap the download icon on a chapter. The app downloads each lesson in that chapter.

## Read Offline

When the device is offline, open a downloaded lesson from Offline Downloads or the lesson route. A banner indicates that downloaded data is being used.

## Pending Sync Banner

If reading progress was saved offline, Offline Downloads shows how many progress items are waiting. The banner disappears when all accepted items sync successfully.

## Sync Now

When online, tap Sync Now to send pending progress immediately. If sync fails, the banner keeps the pending count and shows an error.

## Update Downloaded Lessons

When online, Offline Downloads checks whether a downloaded lesson has changed. If an update is available, tap the update icon. The old copy remains usable if update download fails.

## Delete A Lesson

Tap the delete icon on a downloaded lesson and confirm. Only the current user's downloaded copy is removed.

## Quiz Limitation

Quiz requires network connection in the MVP. This is intentional so quiz answer material and grading logic are not stored for offline use.

## Troubleshooting

- If sync fails, reconnect to a stable network and tap Sync Now.
- If a downloaded lesson says it has an update, update it while online.
- If a lesson is not available offline, open it online and download it first.
