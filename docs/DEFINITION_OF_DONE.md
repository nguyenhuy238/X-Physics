# Definition Of Done

Mot task chi duoc xem la done khi:

- Code chay duoc o local.
- Khong co loi analyze nghiem trong.
- UI co loading/error/empty state neu goi data.
- Service/API co xu ly loi.
- API contract/docs duoc cap nhat neu doi API/model.
- Co test thu cong va ghi cach test trong PR.
- UI co screenshot/video ngan neu co thay doi giao dien.
- PR co mo ta ro module, scope, risk.
- Khong commit secret, build output hoac file ngoai scope khong can thiet.
