# X-Physics Flutter

Giao diện Flutter cho học sinh và admin của X-Physics.

## Cài đặt

```bash
cd flutter_app
flutter pub get
```

## Chạy

```bash
flutter run --dart-define=API_BASE_URL=http://localhost:3000/api
```

## Build

```bash
flutter build apk --dart-define=API_BASE_URL=https://api.example.com/api
```

## Tính năng

- Đăng nhập
- Trang chủ học sinh
- Admin: người dùng, chương, bài học, câu hỏi, thống kê
